# CPP-Coursework

C++ labs and projects from community college and Cal State Fullerton.

| Folder | Course |
| --- | --- |
| `csci110` | Intro to programming: loops, functions, arrays, file input and output |
| `intro-cpp` | Classes, pointers, inheritance, exceptions, templates, a Monte Carlo simulation and a Rock Paper Scissors game |
| `csci140` | Programming assignments: large integer math, classes, recursion, sorting algorithm timing, linked lists |
| `data-structures` | Trees and class practice |
| `operating-systems` | Multithreading with threads |

## Build any program
```
g++ -std=c++17 file.cpp -o program
./program
```
